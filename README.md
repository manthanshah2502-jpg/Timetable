# Daily Topic Planner

A simple mobile-friendly planner that lets you:

- Select any date.
- See the day of the week automatically.
- Add unlimited topic bullet points for that date.
- Tick topics when completed.
- Remove individual topics.
- Clear completed topics.
- Clear all topics for a selected date.
- Keep data saved in the browser using localStorage.
- Install it as an app on supported phones/browsers.

## Put it on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `manifest.json`, `icon.svg`, and this README.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder.
6. Save.
7. GitHub will provide your app's web address.

On a phone, open that address in a supported browser and use **Add to Home Screen / Install app** when offered.

## Important

The planner saves data in the browser on the device. If browser storage is cleared, the saved topics can be lost. This version does not use a server or account.
